Martin Intake: Privacy Policy

Last updated: September 26, 2026

Who uses it

Martin Intake is a private tool used only by its owner, Quiet Engine Media. It is not available to the public.

What it accesses

With read-only Gmail access (the gmail.readonly permission), it reads messages in the owner's business inbox that carry one label and come from a single pre-approved sender address. It cannot send, change or delete email.

What it does with the data

The plain text of those messages is copied into the owner's private notes on the owner's own computer. It also keeps counts of unread messages, and a log of message IDs and whether each one was accepted, never message content. Messages from anyone else are not stored.

Sharing

No data is sold, shared with third parties, or used for advertising. Data obtained through Google APIs is used only for the purpose above, in line with the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

Sign-in credentials are stored in the operating system's credential store on the owner's computer. Nothing is stored on any outside server.

Revoking access

Access can be removed at any time from the Google Account's Security page, under third-party access.
